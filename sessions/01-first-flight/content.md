## A Great Time to Learn This

As a professional programmer:
- You need to know many things (languages, tools, and processes) in great detail
- This is especially true collaborating in teams at scale
But as a hobbiest/tinkerer using AI:
- You need to know what you want and how to describe it clearly
- You need to understand broad concepts about a few things
- You can ask the AI to teach you what you don't know
So, let's have some fun, shall we?

## Pick an Arcade Game 

Arcade/game clones (1970s–early 80s vibe). Suggestions:

- Pong (1972) — two paddles, one ball, dead simple physics
- Snake — grid-based, no external assets needed
- Breakout — paddle + bricks, good intro to collision detection
- Space Invaders — rows of enemies descending, player shoots up
- Missile Command — draw trajectories, click to intercept
- Asteroids — simple physics/rotation, more ambitious if a student wants a stretch goal
- Space War - like Asteroids, but two sets of controls, a central planet, and an opponent to fight

---

## Pick an AI Coding Partner

- **[Claude](claude.ai)** — strong at coding, free tier available, requires login (email/Google/Apple).
- **[ChatGPT](chatgpt.com)** — the default most students already know, free tier available, requires login.
- **[Gemini](gemini.google.com)** — Google's model, free tier, and it's a natural fit for students who already have school Google accounts since login friction is near-zero for them.
- **[Microsoft Copilot](copilot.microsoft.com)** — runs on OpenAI's models; one of the few that's usable with no signup at all for basic chat, though signing in (Microsoft account) raises usage limits.

---

## Pick a Code Sandbox

- **[CodePen](https://codepen.io)**: free to view/run/fork anonymously; free account needed to save your own pen permanently. No credit-based throttling
- **[JSFiddle](https://jsfiddle.net)**: similar — free, some anonymous use, but saving reliably needs a free login. No credit system either.
- **[CodeSandbox](https://codesandbox.io)**: as above — as long as students pick the plain HTML/CSS/JS template (not a Node/React dev server sandbox), it stays in "Browser Sandbox" territory and won't hit the credit-consuming VM tier at all. Free account still required to save.

---

## Code the Game - First Prompt

Write a complete, single HTML file that runs a simple ___________ game in the browser, using only vanilla HTML, CSS, and JavaScript (no external libraries or build tools). It should work by just pasting the code into an online sandbox. Keep the game simple and playable — classic 1970's-style, minimal graphics (basic shapes/colors, no image assets). Include:
  - Clear on-screen instructions for how to play/use it
  - Keyboard or mouse controls, whichever fits the game
  - A simple win/lose or reset condition if applicable

---

## Test the Game

- Copy the code from the AI (Copy button or Ctrl-C)
- Paste the code into the Sandbox (Ctrl-A to select current content, Ctrl-V to overwrite it)
- Play the Game

---

## Fix the Game - Subsequent Prompts

- Describe defects you want fixed
- Describe changes or enhancments you would like
- Test the Game again until you are satisfied
